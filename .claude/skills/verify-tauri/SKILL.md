# Tauri 実機確認チェックリスト

Vite のみのブラウザプレビューでは Tauri API(fs / dialog / store)が動かない。
以下は `npm run tauri dev` で起動した実機ウィンドウでのみ確認できる項目。

初回起動は Rust のコンパイルが走るため数分かかる(2回目以降は高速)。

## チェックリスト

### ファイル I/O(メニュー「ファイル」またはショートカット)
- [ ] 開く(Ctrl+O)で .adoc を選択 → 新しいタブで開く
- [ ] 編集 → 保存(Ctrl+S)→ タブの dirty ドットが消える
- [ ] 名前を付けて保存(Ctrl+Shift+S)→ Untitled タブにファイル名が付く
- [ ] HTML としてエクスポート → 生成されたファイルがブラウザで開ける

### 保管庫
- [ ] メニュー「ファイル > フォルダを開く」で実フォルダを選択 → サイドバーにツリー表示
      (フォルダ/ファイルの Lucide アイコンとシェブロンの開閉回転も確認)
- [ ] 対応拡張子(adoc/asciidoc/asc/txt)だけが表示され、ドット始まり・
      空フォルダが隠れている
- [ ] ツリーのファイルをクリック → タブで開く(同じファイルは既存タブが
      アクティブになりタブが増えない)
- [ ] フォルダ内にファイルを追加 → ↻ で反映される

### 設定の永続化
- [ ] メニュー「ファイル > 設定...」でテーマ・フォントサイズ・デバウンスを変更 → 即時反映
- [ ] メニュー「表示 > テーマ」からの切替も反映され、チェックマークが追従する
- [ ] アプリを終了して再起動 → 変更した設定が残っている
      (AppConfig ディレクトリの settings.json)

### メニューバー・ステータスバー
- [ ] メニューが開いている間、別メニューへのホバーで切り替わる。Esc・外側クリックで閉じる
- [ ] ステータスバーの行・列がカーソル移動に、文字数が編集に追従する

### プレビューのリンクと画像(M8)
- [ ] sample フォルダを開き 00-index.adoc を表示 → プレビュー内の各ファイルへの
      リンクをクリック → タブとして開く(アプリが初期表示に戻らない)
- [ ] 外部 URL リンク(05 の Asciidoctor 公式など)をクリック → システムの
      既定ブラウザで開く(WebView 内で遷移しない)
- [ ] 05 のローカル画像(`images/sample-logo.svg`)がブロック・インラインとも
      表示される(asset プロトコル。ブラウザプレビューでは表示されないのが正常)
- [ ] 対応外拡張子へのリンクや無題文書での相対リンクは何も起きない

### CSP / XSS
- [ ] 起動後、WebView の DevTools コンソールに CSP 違反エラーが出ていない
      (エディタ・プレビュー・設定ダイアログを一通り触った状態で)
- [ ] `++++` パススルーブロックに `<script>alert(1)</script>` を書いた .adoc を
      開いてもアラートが出ない(プレビューはサニタイズされる)
- [ ] 同じ文書を HTML 出力するとパススルーが生きている(エクスポートは
      サニタイズしない仕様)

### 印刷 / PDF
- [ ] Ctrl+P → OS の印刷ダイアログが開き、プレビュー内容だけが対象になる
      (メニューバー・タブバー・サイドバー・ステータスバー・エディタは含まれない)
- [ ] 表示モードを「エディタのみ」にした状態で Ctrl+P →
      プレビューが(画面上は非表示でも)印刷対象として出力され、白紙にならない(M9)

### 表示モード切り替え(M9)
- [ ] タブバー右端の2ボタン・Ctrl+K V・Ctrl+Shift+V・「表示」メニューの
      いずれからでもエディタのみ/分割/プレビューのみが切り替わり、
      3経路で状態が食い違わない(メニューのチェックマークも追従する)
- [ ] プレビューのみ → 分割から入っていた場合は分割に、エディタのみから
      入っていた場合はエディタのみに戻る

### シンタックスハイライト(M10)
- [ ] sample の 03-blocks.adoc を開き、javascript/python/rust/json のコードブロックが
      色付きで表示され、plantuml ブロックは色なしのプレーン表示のままになる
- [ ] HTML エクスポート → 生成 HTML を *ネットワークを切った状態* のブラウザで開き、
      コードブロックが色付きのまま表示される(スクリプト同梱なし・静的焼き込み)
- [ ] Ctrl+P → 印刷プレビューのコードブロックがダークテーマ中でもライト配色になっている

### 作図 / Mermaid(M11)
- [ ] sample の 07-diagrams-mermaid.adoc を開き、フローチャート・シーケンス図・
      状態遷移図が図として描画される(構文エラーの例はコードとエラー表示のまま残る)
- [ ] ダークテーマ状態で 07 を HTML エクスポート → 生成 HTML を
      *ネットワークを切った状態* のブラウザで開き、図がライト配色の SVG で表示される
      (スクリプト同梱なし・外部取得なしで開くだけで見える)
- [ ] ダークテーマ状態で Ctrl+P → 印刷プレビューの図がライト配色になっている
      (画面のダーク図が印刷前に一時的にライトへ描き直され、印刷後に元へ戻る)

### 作図 / Kroki(PlantUML / Draw.io)(M12)
- [ ] 設定で「PlantUML / Draw.io を有効にする」がオフ(既定)のまま
      08-diagrams-plantuml.adoc / 09-diagrams-drawio.adoc を開いてもリクエストが
      一切飛ばない(コードブロックのまま表示される)
- [ ] 設定でオンにすると、CSP を変更していないのに PlantUML の図が表示される
      (tauri-plugin-http が Rust 側で通信するため、静的 CSP の
      connect-src の制約を受けないことの確認。WebView の DevTools
      コンソールに CSP 違反エラーが出ていないことも確認する)
- [ ] 09-diagrams-drawio.adoc は kroki.io のコンパニオンサービス停止状況次第で
      エラー表示になりうる(self-host なら表示される想定。エラーでも
      プレビュー全体は壊れない)
- [ ] krokiEnabled・Kroki サーバー URL を変更してアプリを再起動 →
      設定が残っている(settings.json への永続化)
- [ ] オンの状態で 08-diagrams-plantuml.adoc を HTML エクスポート → 生成 HTML を
      *ネットワークを切った状態* のブラウザで開き、PlantUML の図が
      (data URI に焼き込まれているため)そのまま表示される
- [ ] オフの状態で同じ文書を HTML エクスポート → エクスポート中に
      Kroki サーバーへのリクエストが飛ばず、コードブロックのまま出力される

### バグ修正・使い勝手改善(M13)
- [ ] ウィンドウのサイズ・位置を変えて終了 → 再起動すると前回の状態で開く
      (tauri-plugin-window-state)
- [ ] 保管庫フィルタの切り分け: 「フォルダを開く」でこのリポジトリを選択 →
      **サイドバーのツリー**(選択ダイアログではない)に docs/sample 等の
      対応ファイルを含むフォルダと .adoc/.txt だけが表示され、
      .git・.claude・node_modules(対応ファイルなし)が出ないこと。
      ※ Windows のフォルダ選択ダイアログ自体は「フォルダのみ・ドット始まりも
      表示・ファイル非表示」の見た目になるが、それはフィルタとは無関係
- [ ] タブをたくさん開いてウィンドウを狭める → スクロールバーは出ず、
      左右送り・一覧ボタンが現れる。ホイールでも送れる
- [ ] 片方のタブで下までスクロールして別タブへ切替 → 新しいタブは先頭から、
      戻ると元の位置に復元される(エディタ・プレビューとも)
- [ ] 対応ファイルが 1 つもないフォルダを「フォルダを開く」で選択 →
      サイドバーに「対応ファイル(.adoc / .asciidoc / .asc / .txt)が
      見つかりません」の案内が表示される(空白のままにならない)
- [ ] 対応ファイルがあるフォルダを選択 → サイドバーヘッダーに
      「N ファイル」の件数表示が出る。フォルダ選択ダイアログのタイトルが
      「保管庫にするフォルダを選択」になっている
- [ ] ディバイダを 50% に合わせた状態で、エディタの本文(行番号の右側)と
      プレビューの本文がほぼ同じ幅に見える(行番号ガター分だけエディタが
      狭く見える不具合が直っていること)
- [ ] 分割 or エディタのみ表示で、プレビュー側をクリックしてフォーカスしてから
      Ctrl+F → エディタ側に日本語 UI の検索パネルが開く(WebView ネイティブの
      検索バーではないこと)。プレビューのみ表示で Ctrl+F → 従来どおり
      ネイティブの検索バーが開く
