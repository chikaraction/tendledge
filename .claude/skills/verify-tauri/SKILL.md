# Tauri 実機確認チェックリスト

Vite のみのブラウザプレビューでは Tauri API(fs / dialog / store)が動かない。
以下は `npm run tauri dev` で起動した実機ウィンドウでのみ確認できる項目。

初回起動は Rust のコンパイルが走るため数分かかる(2回目以降は高速)。

## チェックリスト

### ファイル I/O
- [ ] 開く(Ctrl+O)で .adoc を選択 → 新しいタブで開く
- [ ] 編集 → 保存(Ctrl+S)→ タブの dirty ドットが消える
- [ ] 名前を付けて保存(Ctrl+Shift+S)→ Untitled タブにファイル名が付く
- [ ] HTML 出力 → 生成されたファイルがブラウザで開ける

### 保管庫
- [ ] 「フォルダを開く」で実フォルダを選択 → サイドバーにツリー表示
- [ ] 対応拡張子(adoc/asciidoc/asc/txt)だけが表示され、ドット始まり・
      空フォルダが隠れている
- [ ] ツリーのファイルをクリック → タブで開く(同じファイルは既存タブが
      アクティブになりタブが増えない)
- [ ] フォルダ内にファイルを追加 → ↻ で反映される

### 設定の永続化
- [ ] ⚙ でテーマ・フォントサイズ・デバウンスを変更 → 即時反映
- [ ] アプリを終了して再起動 → 変更した設定が残っている
      (AppConfig ディレクトリの settings.json)

### CSP / XSS
- [ ] 起動後、WebView の DevTools コンソールに CSP 違反エラーが出ていない
      (エディタ・プレビュー・設定ダイアログを一通り触った状態で)
- [ ] `++++` パススルーブロックに `<script>alert(1)</script>` を書いた .adoc を
      開いてもアラートが出ない(プレビューはサニタイズされる)
- [ ] 同じ文書を HTML 出力するとパススルーが生きている(エクスポートは
      サニタイズしない仕様)

### 印刷 / PDF
- [ ] Ctrl+P → OS の印刷ダイアログが開き、プレビュー内容だけが対象になる
      (ツールバー・タブバー・サイドバー・エディタは含まれない)
