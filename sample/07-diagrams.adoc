= 作図(Mermaid / PlantUML / Draw.io)
:author: AsciiDoc Editor

Mermaid のコードから図を描けます。図はこのエディタ内で描画され(mermaid.js を
同梱)、*文書の内容が外部に送信されることはありません*。オフラインでも動きます。

== 記法

`[mermaid]` ブロック、または `[source,mermaid]` ブロックに Mermaid の記法を
書きます。どちらでも同じ図になります。

[mermaid]
----
graph TD
  A[開始] --> B{条件?}
  B -->|はい| C[処理する]
  B -->|いいえ| D[何もしない]
  C --> E[終了]
  D --> E
----

== フローチャート

`[source,mermaid]` でも同じように描けます。

[source,mermaid]
----
flowchart LR
  入力 --> 変換 --> 出力
----

== シーケンス図

[mermaid]
----
sequenceDiagram
  participant U as ユーザー
  participant A as アプリ
  participant S as サーバー
  U->>A: 文書を保存
  A->>S: 書き込み要求
  S-->>A: 完了
  A-->>U: 保存しました
----

== 状態遷移図

[mermaid]
----
stateDiagram-v2
  [*] --> 編集中
  編集中 --> 保存済み: 保存
  保存済み --> 編集中: 変更
  保存済み --> [*]
----

== クラス図

[mermaid]
----
classDiagram
  class Document {
    +String title
    +String path
    +Boolean dirty
    +save()
  }
  class Tab
  Document "1" o-- "1" Tab : 表示
  Document <|-- AsciiDocFile
----

== ER 図

[mermaid]
----
erDiagram
  VAULT ||--o{ FILE : contains
  FILE ||--|{ TAB : opens
  VAULT {
    string path
    string name
  }
  FILE {
    string path
    string extension
  }
----

== ガントチャート

[mermaid]
----
gantt
  title 開発スケジュール
  dateFormat YYYY-MM-DD
  section 設計
  要件定義 :done, a1, 2026-07-01, 2d
  設計文書 :active, a2, after a1, 3d
  section 実装
  実装 :a3, after a2, 5d
  検証 :a4, after a3, 2d
----

== テーマ追従

図の配色は、アプリのテーマ(ライト / ダーク / システムに合わせる)に自動で
追従します。「表示」メニューからテーマを切り替えると図が描き直されます。

NOTE: HTML エクスポートと PDF / 印刷では、図は常にライト配色の SVG として
出力されます(他のエクスポート要素と揃えるため)。

== 構文エラーのとき

Mermaid として解釈できない内容を書くと、図には変換されず、元のコードと
エラーメッセージがそのまま表示されます(書きかけの図が消えないようにするため)。

[mermaid]
----
これは Mermaid の記法ではありません
----

== PlantUML / Draw.io(Kroki 経由)

CAUTION: この節の図は、この文書内で完結する Mermaid とは違い、図のソースを
**設定した Kroki サーバーへ送信して** SVG を受け取る方式です。「設定」→
「作図(リモートレンダリング)」でオプトイン(既定は無効)し、サーバー
URL(既定 `kroki.io`、self-host も可)を確認してから使ってください。
オフライン時・サーバーに到達できない場合は、コードブロックの下にエラーが
表示されます(図には壊れません)。

=== PlantUML

`[plantuml]` ブロック、または `[source,plantuml]` ブロックに PlantUML の
記法を書きます。どちらでも同じ図になります。

.シーケンス図
[plantuml]
----
Alice -> Bob: 認証要求
Bob --> Alice: トークン発行
Alice -> Bob: トークン提示
Bob --> Alice: 認可完了
----

.クラス図(source,plantuml)
[source,plantuml]
----
class Document {
  +String title
  +String path
  +Boolean dirty
  +save()
}
class Tab
Document "1" o-- "1" Tab
Document <|-- AsciiDocFile
----

=== Draw.io

`[drawio]` ブロック(`[diagramsnet]` でも同じ)に draw.io の `mxfile` XML を
そのまま書きます。

WARNING: Draw.io(Kroki 側の呼称は "diagramsnet")は、公開の kroki.io では
コンパニオンサービスが停止していることがあり、その場合は下のブロックが
エラー表示になります。self-host した Kroki(diagramsnet コンパニオン込み)
では動作します。

[drawio]
----
<mxfile>
  <diagram name="Page-1">
    <mxGraphModel dx="800" dy="600" grid="1" gridSize="10">
      <root>
        <mxCell id="0"/>
        <mxCell id="1" parent="0"/>
        <mxCell id="2" value="こんにちは" style="rounded=1" vertex="1" parent="1">
          <mxGeometry x="40" y="40" width="120" height="60" as="geometry"/>
        </mxCell>
      </root>
    </mxGraphModel>
  </diagram>
</mxfile>
----

=== 構文エラーのとき(PlantUML)

Kroki サーバーが「解釈できない」と判断した場合も、Mermaid と同じくコードは
消えず、エラーメッセージが直下に表示されます。

[plantuml]
----
これは PlantUML の記法ではありません
----
