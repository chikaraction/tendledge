== 目次(TOC)の自動生成

文書ヘッダ(タイトル行の直後)に `:toc:` と書くだけで、見出しから目次が自動生成されます。
実際にこの文書の冒頭にも目次が表示されているはずです。
既定では見出しレベル2までが目次に載りますが、`:toclevels: 3` のように指定すると
含める深さを変更できます。

== インライン文字装飾

// 記法をそのまま見せる箇所は `+...+`(パススルー)で囲む。
// 素の `*...*` だとバッククォート内でも太字が解釈されてしまう。
* *太字* は `+*アスタリスク*+` で囲みます。
* _斜体(強調)_ は `+_アンダースコア_+` で囲みます。
* `モノスペース` は バッククォートで囲みます。
* `+*_太字と斜体の組み合わせ_*+` のようにネストもできます → *_こんな感じ_*
* 上付き文字: E=mc^2^
* 下付き文字: H~2~O
* [.underline]#下線# や [.line-through]#取り消し線# のようにロール指定もできます。
* 改行を強制したいときは行末に `+` を置きます。 +
これは強制改行された行です。
