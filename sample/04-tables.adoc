= 表(テーブル)
:author: AsciiDoc Editor

== 基本の表

`|===` で囲み、`|` でセルを区切ります。1行に1セルずつ書き、空行で行を区切ります。

// 先頭の行だけを1行にまとめて直後に空行を置くと「暗黙のヘッダー行」に
// なってしまうため、基本の表ではセルを行分けして書く。
[cols="1,1"]
|===
| セル 1
| セル 2

| セル 3
| セル 4
|===

== ヘッダー行付きの表

[cols="1,2", options="header"]
|===
| 項目 | 説明

| AsciiDoc
| 軽量マークアップ言語の1つ

| Asciidoctor
| AsciiDoc を HTML 等に変換するツール
|===

== 列幅・配置指定

`cols` で列ごとの幅と配置を指定できます(`^1` = 中央揃え・幅1)。
セル単位で変えたいときは `>|` のように演算子を `|` の *前* に置きます
(セル内容側に書くと文字として表示されてしまいます)。

[cols="1,3,^1", options="header"]
|===
| No | 内容 | 状態

| 1
| 左寄せの説明文(状態列は cols の指定で中央揃え)
| OK

| 2
| 次のセルはセル単位の演算子で右寄せにした例
>| NG
|===

== セル結合(列・行)

`2+|` は右に2列分、`.2+|` は下に2行分の結合です。

[cols="1,1,1", options="header"]
|===
| 列1 | 列2 | 列3

2+| 2列分を結合したセル
| 通常のセル

.2+| 2行分を結合したセル
| B1
| C1

| B2
| C2
|===

`列.行+` の形で列と行を同時に結合することもできます。

[cols="1,1,1"]
|===
| A1
| B1
| C1

2.2+| 2列×2行を結合したセル
| C2

| C3
|===

== セル内にAsciiDoc記法を使う(a指定)

`a|` のように演算子 `a` を `|` の前に置くと、そのセル内でリストや
コードブロックなどの AsciiDoc 記法が使えます。セルの内容は演算子と
同じ行に続けても、次の行から書いても構いません(どちらも有効な記法です)。

[cols="1,2"]
|===
| 項目 | 内容

| リスト
a|
* 項目1
* 項目2

| コード
a|
[source,python]
----
print("cell内のコードブロック")
----
|===
