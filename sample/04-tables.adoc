= 表(テーブル)
:author: AsciiDoc Editor

== 基本の表

`|===` で囲み、`|` でセルを区切ります。

[cols="1,1"]
|===
| 列 A | 列 B

| セル 1
| セル 2

| セル 3
| セル 4
|===

== ヘッダー行付きの表

[cols="1,2", options="header"]
|===
| 項目 | 説明

| AsciiDoc
| 軽量マークアップ言語の1つ

| Asciidoctor
| AsciiDoc を HTML 等に変換するツール
|===

== 列幅・配置指定

[cols="1,3,^1", options="header"]
|===
| No | 内容 | 状態

| 1
| 左寄せの説明文
| ^OK

| 2
| もう1つの説明文
| ^NG
|===

== セル結合(列・行)

[cols="1,1,1"]
|===
2+| 2列分を結合したセル | 通常のセル

| A
| B
| C
|===

== セル内にAsciiDoc記法を使う(a指定)

[cols="1,2"]
|===
| 項目 | 内容

| リスト
a|
* 項目1
* 項目2

| コード
a|
[source,python]
----
print("cell内のコードブロック")
----
|===
