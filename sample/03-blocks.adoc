= ブロック要素
:author: AsciiDoc Editor

== コードブロック(リスティングブロック)

`----` で囲むとコードブロックになり、`[source,言語名]` で言語を指定すると
シンタックスハイライトが付きます。

[source,javascript]
----
const greet = (name) => `Hello, ${name}!`;
console.log(greet("AsciiDoc"));
----

[source,python]
----
def greet(name: str) -> str:
    # コメントもハイライトされます
    return f"Hello, {name}!"
----

[source,rust]
----
fn main() {
    println!("Hello, AsciiDoc!");
}
----

[source,json]
----
{
  "name": "AsciiDoc Editor",
  "milestone": 10
}
----

対応していない言語(例: `plantuml`)や `[source]` の言語指定なしの場合は、
色付けなしのプレーンな表示になります。

[source,plantuml]
----
@startuml
Alice -> Bob: Hello
@enduml
----

== リテラルブロック

`....` で囲むと、整形済みテキストとしてそのまま表示されます。

....
これはリテラルブロックです。
   インデントや空白もそのまま保持されます。
....

== 引用ブロック

`____` で囲むと引用として表示されます。

____
これは引用ブロックです。
出典を付けることもできます。

-- 著者名, 出典
____

== 例示ブロック

`====` で囲むと「例」として表示されます。`.タイトル` を直前の行に置くと
ブロックにタイトルが付きます。

.タイトル付きの例示ブロック
====
これは例示ブロックです。ネストして他のブロックを含められます。

****
例示ブロックの中にサイドバーをネストした例です。
****
====

== サイドバー

`****` で囲むと補足情報用のサイドバーになります。こちらも `.タイトル` が使えます。

.コラム: サイドバーの使いどころ
****
これはサイドバーです。本文の流れから少し離れた補足情報を書くのに使います。
****

== オープンブロック

`--` で囲むオープンブロックは、特別な意味を持たない汎用の入れ物です。

--
これはオープンブロックです。段落やリストなど任意の内容を入れられます。
--

== パススルーブロック

`pass:c[++++]` で囲むと、AsciiDoctor の変換を通さず生の HTML がそのまま出力されます。

++++
<p style="color: var(--color-accent, #06c);">これは passthrough ブロックによる生 HTML です。</p>
++++

== 横罫線

段落の区切りとして水平線を入れられます。
