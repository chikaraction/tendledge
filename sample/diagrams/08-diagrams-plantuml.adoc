この文書内では完結しません。図のソースを**設定した Kroki サーバーへ送信して**

使ってください。オフライン時・サーバーに到達できない場合は、コードブロックの
下にエラーが表示されます(図には壊れません)。

== 記法

`[plantuml]` ブロック、または `[source,plantuml]` ブロックに PlantUML の
記法を書きます。どちらでも同じ図になります。

.シーケンス図
[plantuml]
----
Alice -> Bob: 認証要求
Bob --> Alice: トークン発行
Alice -> Bob: トークン提示
Bob --> Alice: 認可完了
----

.クラス図(source,plantuml)
[source,plantuml]
----
class Document {
  +String title
  +String path
  +Boolean dirty
  +save()
}
class Tab
Document "1" o-- "1" Tab
Document <|-- AsciiDocFile
----

== 構文エラーのとき

消えず、エラーメッセージが直下に表示されます。

[plantuml]
----
これは PlantUML の記法ではありません
