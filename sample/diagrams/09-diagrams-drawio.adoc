= 作図(Draw.io・Kroki 経由)
:author: AsciiDoc Editor
:toc:

CAUTION: この節の図は、link:07-diagrams-mermaid.adoc[Mermaid]とは違い、
この文書内では完結しません。図のソースを**設定した Kroki サーバーへ送信して**
SVG を受け取る方式です。「設定」→「作図(リモートレンダリング)」でオプトイン
(既定は無効)し、サーバー URL(既定 `kroki.io`、self-host も可)を確認してから
使ってください。オフライン時・サーバーに到達できない場合は、コードブロックの
下にエラーが表示されます(図には壊れません)。

== 記法

`[drawio]` ブロック(`[diagramsnet]` でも同じ)に draw.io の `mxfile` XML を
そのまま書きます。

WARNING: Draw.io(Kroki 側の呼称は "diagramsnet")は、公開の kroki.io では
**動作しません**(一時的な障害ではなく、メンテナが「追加リソースが必要でコストが
かかるため動かしていない」と公式に表明している既定の仕様です。
https://github.com/yuzutech/kroki/issues/1726 参照)。下のブロックはこの
既定 URL のままではエラー表示になります。使うには Kroki を self-host し、
`yuzutech/kroki-diagramsnet` コンパニオンコンテナを併用してください
(docker-compose の設定例は
link:../../docs/milestone-12-plan.md[docs/milestone-12-plan.md] に記載)。
起動後は「設定」→「作図(リモートレンダリング)」の Kroki サーバー URL を
その self-host 先(例: `http://localhost:8000`)に変更するだけで動きます。

[drawio]
----
<mxfile>
  <diagram name="Page-1">
    <mxGraphModel dx="800" dy="600" grid="1" gridSize="10">
      <root>
        <mxCell id="0"/>
        <mxCell id="1" parent="0"/>
        <mxCell id="2" value="こんにちは" style="rounded=1" vertex="1" parent="1">
          <mxGeometry x="40" y="40" width="120" height="60" as="geometry"/>
        </mxCell>
      </root>
    </mxGraphModel>
  </diagram>
</mxfile>
----
