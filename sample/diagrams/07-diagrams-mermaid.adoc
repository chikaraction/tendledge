= 作図(Mermaid)
:author: AsciiDoc Editor
:toc:
:toc-title: 目次
:toclevels: 3
:numbered:

Mermaid のコードから図を描けます。図はこのエディタ内で描画され(mermaid.js を
同梱)、*文書の内容が外部に送信されることはありません*。オフラインでも動きます。

== 記法

`[mermaid]` ブロック、または `[source,mermaid]` ブロックに Mermaid の記法を
書きます。どちらでも同じ図になります。

[mermaid]
----
graph TD
  A[開始] --> B{条件?}
  B -->|はい| C[処理する]
  B -->|いいえ| D[何もしない]
  C --> E[終了]
  D --> E
----

== フローチャート

`[source,mermaid]` でも同じように描けます。

[source,mermaid]
----
flowchart LR
  入力 --> 変換 --> 出力
----

== シーケンス図

[mermaid]
----
sequenceDiagram
  participant U as ユーザー
  participant A as アプリ
  participant S as サーバー
  U->>A: 文書を保存
  A->>S: 書き込み要求
  S-->>A: 完了
  A-->>U: 保存しました
----

== 状態遷移図

[mermaid]
----
stateDiagram-v2
  [*] --> 編集中
  編集中 --> 保存済み: 保存
  保存済み --> 編集中: 変更
  保存済み --> [*]
----

== クラス図

[mermaid]
----
classDiagram
  class Document {
    +String title
    +String path
    +Boolean dirty
    +save()
  }
  class Tab
  Document "1" o-- "1" Tab : 表示
  Document <|-- AsciiDocFile
----

== ER 図

[mermaid]
----
erDiagram
  VAULT ||--o{ FILE : contains
  FILE ||--|{ TAB : opens
  VAULT {
    string path
    string name
  }
  FILE {
    string path
    string extension
  }
----

== ガントチャート

[mermaid]
----
gantt
  title 開発スケジュール
  dateFormat YYYY-MM-DD
  section 設計
  要件定義 :done, a1, 2026-07-01, 2d
  設計文書 :active, a2, after a1, 3d
  section 実装
  実装 :a3, after a2, 5d
  検証 :a4, after a3, 2d
----

== 円グラフ

[mermaid]
----
pie title 記法の使用割合
  "見出し・段落" : 40
  "リスト" : 25
  "表" : 20
  "コード" : 15
----

== テーマ追従

図の配色は、アプリのテーマ(ライト / ダーク / システムに合わせる)に自動で
追従します。「表示」メニューからテーマを切り替えると図が描き直されます。

NOTE: HTML エクスポートと PDF / 印刷では、図は常にライト配色の SVG として
出力されます(他のエクスポート要素と揃えるため)。

== 構文エラーのとき

Mermaid として解釈できない内容を書くと、図には変換されず、元のコードと
エラーメッセージがそのまま表示されます(書きかけの図が消えないようにするため)。

[mermaid]
----
これは Mermaid の記法ではありません
----
