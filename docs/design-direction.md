# デザイン方向: Slate

2026-07-05 決定。以降の機能実装はこの文書を北極星とし、新しい UI を足すときは
ここで定義した骨格とトークンに従う。見た目の細部の磨き込み(ポリッシュパス)は
機能が出揃った後に 1 回まとめて行う。

## 決定事項

| 項目 | 決定 | 備考 |
| --- | --- | --- |
| 方向 | **A · Slate**(Obsidian 正統派) | ダーク基調 + 紫アクセント。検討した 4 案(Slate / Paper / Graphite / Workbench)から選定 |
| メニューバー | **採用** | 現在のツールバー(文字ボタン 8 個)を置き換える |
| ステータスバー | **採用** | 行・列 / 文字数 / 変換時間を常時表示 |
| アイコンリボン | 不採用 | メニューバーが役割を担う |
| コマンドパレット | 今回は見送り | 将来採用する場合は Ctrl+P(現: 印刷)の衝突解消が必要 |
| アイコン | **Lucide**(ISC) | Obsidian 本体と同じセット。ISC は MIT 相当の許諾型で組み込み配布可 |
| 外部デザインシステム | **不採用**(Sparkle は見送り) | 下記 ADR 参照 |

### ADR: Sparkle Design System を採用しない

[Sparkle](https://sparkle-design.goodpatch.com/) は候補になったが、以下の理由で見送り、
自前トークン + 手書き CSS を継続する。

1. **規約**: 利用範囲が「自社内における設計・開発・制作業務」に限定され、
   「改変し、再配布またはサービス・製品に組み込んで第三者に提供する行為」が禁止。
   本アプリは GitHub 公開・配布前提のため組み込み不可(2026-07-05 時点の規約)。
2. **技術**: 実装が React 前提。本アプリは意図的に vanilla TS であり、
   導入には ui/ 全書き換えが必要。UI の主役は CodeMirror とプレビューなので
   デザインシステムがカバーする面積が小さく、割に合わない。
3. **トーン**: ライトで親しみやすいプロダクト UI 向けであり、Slate(ダーク基調の
   エディタ)と方向が合わない。ダークモード対応も明記なし。

見た目の参考(余白・寸法の感覚)として眺めるのは規約上問題ない。

## デザイントークン

styles.css の CSS 変数を以下に差し替える。既存のテーマ機構
(`data-theme` 属性 + `prefers-color-scheme`)はそのまま使う。
**Slate はダークファースト**: デザインの基準はダーク側で、ライトは同じ構造の淡色版。

### ダーク(基準)

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#1b1b22` | エディタ・プレビューの地 |
| `--bg-subtle` | `#16161c` | メニューバー・タブバー・ステータスバーの地 |
| `--bg-raised` | `#202028` | サイドバー・ダイアログ・ホバー面 |
| `--fg` | `#dcdce4` | 本文 |
| `--fg-muted` | `#8d8da0` | 補助テキスト・非アクティブタブ |
| `--border` | `#2c2c36` | 区切り線(基本 1px、可能な箇所は控えめに) |
| `--accent` | `#a78bfa` | アクティブ表示・リンク・フォーカス |
| `--error` | `#e5766c` | エラー表示 |
| `--code-bg` | `#26262f` | コード面(インライン・ブロック)。ダークでは地より明るくして判別を保つ(M8 追加) |

### アドモニション種類別カラー(ライト/ダーク共通)

プレビューの `NOTE`/`TIP`/`IMPORTANT`/`WARNING`/`CAUTION` は、伝統的な
AsciiDoc/Font Awesome の配色慣習に合わせた固有色を使う。テーマによらず
同じ値(十分な彩度があり、ライト・ダークどちらの `--bg-subtle` 上でも
白抜きアイコンとのコントラストが保てるため)。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--note-color` | `#2f80ed`(青) | NOTE のアイコン背景・左罫線 |
| `--tip-color` | `#d9a005`(金) | TIP のアイコン背景・左罫線 |
| `--important-color` | `#e0393e`(赤) | IMPORTANT のアイコン背景・左罫線 |
| `--warning-color` | `#e08a1e`(橙) | WARNING のアイコン背景・左罫線 |
| `--caution-color` | `#d8481e`(赤橙) | CAUTION のアイコン背景・左罫線 |

### ライト(淡色版)

| 変数 | 値 |
| --- | --- |
| `--bg` | `#ffffff` |
| `--bg-subtle` | `#f4f4f7` |
| `--bg-raised` | `#ececf1` |
| `--fg` | `#26262e` |
| `--fg-muted` | `#6f6f7e` |
| `--border` | `#e1e1e8` |
| `--accent` | `#6d5bd0`(ライト地でのコントラスト確保のため濃いめ) |
| `--error` | `#b0362c` |
| `--code-bg` | `#f4f4f7`(ライトでは bg-subtle と同値でよい) |

### タイポグラフィ・その他

- フォントは現行を維持(UI: system-ui 系 / エディタ: ui-monospace 系)。
  プレビューもサンセリフのまま(Slate は装飾より一貫性を取る)
- 角丸: コントロール 6px / パネル 8px(現行踏襲)
- `--bg-raised` は新設。既存の `--bg-subtle` 一本だった階層を
  「地 < subtle < raised」の 3 段に増やし、Obsidian 的な奥行きを出す

## 骨格の設計

### メニューバー(ツールバー置き換え)

**カスタム HTML メニューバー**を採用する(Tauri のネイティブメニューは
OS 統合される代わりにテーマ追従・クロスプラットフォーム一貫・ブラウザプレビューでの
動作確認ができないため不採用)。

構成案(実装時に調整可):

```
ファイル(F)  新規 / 開く / フォルダを開く / 保存 / 名前を付けて保存 / エクスポート(HTML・PDF) / 設定
表示(V)     サイドバー表示切替 / テーマ(ライト・ダーク・システム)
```

- 既存のキーボードショートカットはメニュー項目の右側に表示する
- 設定(⚙)はメニュー配下に移す。ダイアログ自体は現行のまま
- メニューの開閉状態・項目定義は `core/`(純粋ロジック)に置き、
  DOM 描画だけを `ui/menubar.ts` が担う(テストファースト)

### ステータスバー

下端に常時表示。左から:

```
[保管庫名(開いていれば)]           [行 24, 列 8] [1,240 文字] [12 ms]
```

- 変換時間表示(現在ツールバー右端の `#status`)はここへ移動
- 文字数・カーソル位置の算出は `core/` の純粋関数として実装しテストする
- 印刷時は非表示(`@media print` に追加)

### レイアウト全体

```
┌──────────────────────────────────────┐
│ メニューバー                            │ ← --bg-subtle
├──────────────────────────────────────┤
│ タブバー                               │ ← --bg-subtle
├──────────┬────────────┬──────────────┤
│ サイドバー │ エディタ     │ プレビュー     │ ← sidebar は --bg-raised
├──────────┴────────────┴──────────────┤
│ ステータスバー                          │ ← --bg-subtle
└──────────────────────────────────────┘
```

## 実装計画(milestone 7 として)

`milestone` スキルのワークフローに従う。順序:

1. **トークン差し替え** — styles.css の変数定義のみ変更(全 UI が一括で Slate 化)
2. **ステータスバー** — core/ に文字数・カーソル位置の純粋関数 → ui/statusbar.ts
3. **メニューバー** — core/ にメニューモデル → ui/menubar.ts、ツールバー撤去
4. **Lucide 導入** — タブの × / ツリーのフォルダ・ファイル / ↻ など最小セットから

各ステップ完了ごとにコミット。3 が最も大きい(ショートカット表記・ボタン配線の移設)。
