# バックログ(マイルストーン積み残し・保留項目)

特定のマイルストーンに紐づけずに温めておく改善候補を管理する。
マイルストーンの計画時にここへ項目を移す/ここから拾うことで、
各 `docs/milestone-N-plan.md` のスコープを純粋に保つ。
着手するときは roadmap のマイルストーンに昇格させるか、単発の feature ブランチで対応し、
完了したら項目を消す(経緯はコミット履歴に残る)。

## エディタの検索・置換 UI(出自: M13 #11・需要確認待ち)

- M13 で Ctrl+F を WebView ネイティブ検索バーに統一した際、CodeMirror
  検索パネルの置換(replace / replace all)機能が入口を失った。
- 置換の需要が出たら、CodeMirror の `openSearchPanel` をメニュー
  (編集 > 置換)や Ctrl+H で露出する形で復活させる。
  パネルの見た目は Slate トークンでスタイルし直すこと(既定は英語 UI の素の見た目)。
- ネイティブ検索は CodeMirror の仮想化により長文でエディタ側の画面外ヒットを
  拾えない制約もあるため、不満が出たらここで合わせて再検討する。

## 図の拡大表示(出自: M11 Mermaid・需要確認待ち)

- ガントチャート等の横長の図が本文カラム(46rem)に縮んで見にくい。
- 設定いじりの小手先対応ではなく、クリックで拡大(ライトボックス)や
  図だけ全幅表示のような機能として設計する。
- 当座はプレビューのフォントサイズ連動拡大(`--diagram-scale`)で代用できる。
- M12(Kroki 経由の PlantUML / Draw.io)で図の種類が増えると需要も増える見込み。
  対応するならリモート図(`<img>`)とローカル図(inline SVG)の両方に効く設計にする。
